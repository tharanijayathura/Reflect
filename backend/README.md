# Reflect Fashion — Backend API

This directory contains the backend API server for Reflect Fashion.

## Getting Started

```bash
cd backend
npm install
npm run dev
```

## Structure

```
backend/
├── src/
│   └── index.ts        # Server entry point
├── package.json
└── tsconfig.json
```

## Planned Features

- **Product Catalog API** — CRUD operations for products
- **Order Management** — Create, update, track orders
- **User Authentication** — JWT-based auth system
- **Payment Gateway** — Stripe/PayHere integration
- **Inventory Management** — Stock tracking and alerts
